Violation Taxonomy

Six Ways Reasoning Fails

Nous formalizes every failure mode in the epistemic logic of agent cognition. Each type is independently detectable, independently scorable.

GT-01
ModusPonensViolation
Agent asserts P and P→Q but fails to derive Q, or derives ¬Q. The bedrock inference rule broken at the operational level.
GT-02
BeliefRevisionFailure
New evidence is received but prior contradictory belief persists without retraction. AGM postulate violation at runtime.
GT-03
ModalScopeError
Necessary and possible operators conflated. □P treated as ◇P or vice versa, corrupting downstream modal reasoning chains.
GT-04
TemporalCoherenceViolation
Claims indexed to time T₁ are applied at T₂ without justification. The session timeline becomes internally inconsistent.
GT-05
ReferentialOpacityFailure
Substitution of co-referential terms inside belief contexts — violating Frege's principle within the agent's propositional attitudes.
GT-06
EpistemicClosureViolation
Agent knows P and knows P→Q but fails to register knowledge of Q. The closure principle of epistemic logic is breached.

Process

How Nous
Watches

Five steps from raw reasoning trace to formal coherence score. Every step is deterministic. Every violation is logged. No thought escapes the graph.

nous — reasoning-monitor v1.0.0
› [01] Session begins. Beliefs extracted from reasoning trace. CommitmentExtractor parses 143 propositions.
› [02] Each claim enters the commitment graph as a typed node. Edges inferred from logical dependency.
› [03] Entailment engine checks every new action against prior commitments. O(V+E) traversal per step.
› [04] Violation detected — TemporalCoherenceViolation at step 7. Belief from T₁ applied without anchoring at T₄.
› [05] Full graph exported. Session coherence score: 0.842. Report: 3 violations, 7 types checked, 0 false positives.
Integration

How It Plugs In

Three surfaces. One reasoning integrity layer. Works wherever your AI runs.

01 — Python Library
pip install nous
Drop into any Python project. Works with any agent trace — Claude, GPT-4, Gemini, or your own model. Three methods at core: step(), state(), closure().
pip install git+https://github.com/sayang7/nous
02 — Live Dashboard
Stream. Verify. Graph.
The Nous v2 frontend streams reasoning steps in real time, flags violations as they occur, and renders the commitment graph interactively. Step into any node to trace the inference chain.
python app.py # localhost:5000
03 — Browser Extension
A voice in your AI's head
An installable sidebar that watches Claude, ChatGPT, and Gemini live — flagging belief-action violations as they stream, inline, in the model's own response.
